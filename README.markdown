# Project_CS

Этот репозиторий содержит коллекцию учебных проектов, разработанных в рамках курса по информатике. Каждый проект реализован на языке C# и охватывает различные аспекты программирования и концепции информатики.

## Проекты

- **Clones**: Система для управления клонами, которые могут обучаться значениям, возвращаться к предыдущим состояниям и клонироваться, сохраняя независимость состояний.
- **Digger**: Игра, в которой игрок перемещается по карте, копает землю, собирает золото и избегает монстров.
- **DistanceTask**: Реализация функций для вычисления расстояния от точки до отрезка и между двумя точками.
- **Dungeon**: Проект, связанный с поиском пути в подземелье, вероятно, с использованием алгоритма поиска в ширину (BFS).
- **Fractals**: Реализация алгоритмов для генерации фрактальных узоров, таких как фрактал Дракона.
- **GaussAlgorithm**: Реализация метода Гаусса для решения систем линейных уравнений.
- **GeometryPainting**: Инструмент или приложение для рисования геометрических фигур.
- **GeometryTasks**: Решения различных задач вычислительной геометрии.
- **HotelAccounting**: Система для управления учетом в отеле, включая, возможно, ценообразование номеров и занятость.
- **LimitedSizeStack**: Реализация структуры данных стека с ограниченным размером.
- **Mazes**: Алгоритмы для генерации и решения лабиринтов.
- **Names**: Задачи, связанные с обработкой и манипуляцией именами, например, сортировкой или поиском.
- **Passwords**: Инструменты для проверки надежности паролей или генерации безопасных паролей.
- **PocketGoogle**: Упрощенный поисковый движок или система индексации текста.
- **Rectangles**: Задачи вычислительной геометрии, связанные с прямоугольниками, такие как определение пересечений или вычисление площади.
- **Rivals**: Проект, моделирующий конкуренцию или соперничество, возможно, в виде игры или алгоритма.

Каждый проект находится в отдельной папке и содержит исходный код. Для получения дополнительной информации о каждом проекте обратитесь к соответствующим папкам.
